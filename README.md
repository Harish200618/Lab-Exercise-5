# Lab-Exercise-5
## Aim:
To analyze two different UX project scenarios by identifying user problems, selecting appropriate UX research methods, and creating user personas to better understand user needs and improve the overall user experience.

## Algorithm:
1.Select two UX project scenarios (e.g., E-commerce Website and Health Appointment App). 2.Study the target users and identify their pain points. 3.Write clear UX problem statements using the template: "[User] needs a way to [achieve goal] because [obstacle], which results in [impact]." 4.Identify suitable UX research methods such as surveys, interviews, usability testing, or diary studies. 5.Justify why the selected research methods are appropriate for each scenario. 6.Create at least two user personas for each scenario, including: 7.Demographics 8.Goals 9.Behaviors 10.Pain Points 11.Motivation 12.Review the personas and research findings to ensure they address the identified UX problems. 13.Compile the work into a report and export it as a PDF.

Two UX project scenarios were successfully analyzed by identifying user pain points, writing UX problem statements, selecting appropriate research methods with justification, and creating user personas. The study provided a clear understanding of user needs and demonstrated how user-centered design techniques can be applied to develop effective and user-friendly digital products.
